# 精剪

脚本在 vlog-pipeline 的 `scripts/` 里（`.claude/skills/vlog-pipeline/scripts/`）。要读的参考：`references/剪辑规范.md`（画面节奏、画质、声音、交付规格）。

## 流程

1. **收实录**：复制进 `inputs/<条>/`，`probe.py` 看一眼；HDR 先 `to_sdr.py`（画面用 SDR 版，声音两个版本一样）。
2. **转写，要逐字时间**：
   ```
   <venv>/bin/python scripts/transcribe.py <实录> --words --prompt "这条的口播开头一两句，加专有名词" --out outputs/<条>/素材盘点/转写
   ```
   `--prompt` 放口播稿开头一两句和专有名词，识别会准很多。
3. **对齐**：`python3 scripts/align_vo.py <时间线.json> <实录.json>`，先不加 `--write` 看结果：
   - **覆盖率低于 70%** 的段：多半对错位置，对照转写手动定 `vo`。
   - **没对上的录音**：开头的语气词（"啊，"）、重录的句子、NG。同一句录了几遍，用最后完整的一遍；语气词让开头更自然的就留（把 `vo` 的入点往前挪、`text` 补上）。
   - 看着没问题再加 `--write` 写回（会同时填好 `voice`）。
4. **按实录改字幕**：创作者录的时候常顺口改词。逐段对照「实际说的」，把时间线的 `text` 改成实录的话（转写听错的字按常识和稿子纠正，比如"一件"是"一键"）。字幕、口播终版都从这里来，必须和实录一字不差。
5. **重排画面**：`python3 scripts/timeline.py <时间线.json>` 看新的每段时长。实录通常和估时差不少，逐段调画面：词和画面要对上（说到"翻转屏"时正好切到翻屏的画面），每个画面的入点和时长按素材盘点里的关键瞬间重新定。出镜段（`talk`）会自动取实录同一时间段的画面，不用管。
6. **渲染**：
   ```
   python3 scripts/render.py <时间线.json> outputs/<条>/精剪-vN-含口播无字幕.mp4
   ```
   还有占位画面时它会提醒；要交的话文件名写明"占位"。
7. **自查**：`python3 scripts/qa.py <精剪.mp4> <时间线.json> --sheet <临时目录>/qa`，看规格、响度（约 -16 LUFS）、黑帧、定格、剪接点附近的跳帧，有问题的剪接点看拼图确认。再用 `contact_sheet.py --at` 抽改过的地方看一眼。交付前派子代理 `vlog-video-qa` 做一遍独立检查。
8. **交付**：给创作者精剪文件，附：总长、这版改了什么、在剪映里要补什么（字幕 = 口播终版、需要的角标或标签、BGM）。同时更新 `分镜脚本` 和 `口播`（`timeline.py --docs`，tag 用 vN 或"终版"）。
9. **改**：创作者的意见改进时间线，重新渲染。**已经定了的段尽量别动**，只改被点名的地方。

## 常见的修改和怎么改

| 创作者说 | 改法 |
|---|---|
| "这里有几帧跳" | 多半是素材自带剪接点被带进来了（引用上一条成片时最常见）。`qa.py` 会列出剪接点附近的切换；把那个画面的 `in` 往后挪到剪接点之后 |
| "这段太慢了" | 空镜加 `speed` 1.5 左右；展示变化的镜头，过程加速，结果原速停留（拆成两个画面） |
| "这个变化没剪进去" | 用 `contact_sheet.py --every 0.25` 看那段素材，找到变化开始和结束的时间，入点放在变化前 |
| "最后一句说慢了" | 那段加 `tempo`（1.15–1.2，不变调） |
| "开头那个语气词留着" | `vo` 入点往前挪到语气词之前，`text` 补上 |
| "清晰度、质感不够" | 低清素材默认已经降噪 + 放大 + 锐化；还不够就 `grade: light`，或给那几个画面 `sharpen` 调到 0.6–0.7、`denoise: strong`。最有效的还是要原片。不用 AI 超分（人脸会变） |
| "这页做得粗糙" | 图文页、介绍卡按账号配置里的视觉风格重做成 PNG 或视频，作为 `image` / `clip` 放进时间线 |
