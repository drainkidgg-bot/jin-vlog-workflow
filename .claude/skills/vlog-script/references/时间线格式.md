# 时间线格式（时间线.json）

一条视频一份，放在 `outputs/<条>/时间线.json`。路径都写相对项目根目录的（`inputs/2026-11-相机体验会/IMG_0101.mov`），也可以写绝对路径。

## 例子

虚构的场景：一个摄影爱好者去了一场相机新品体验会。

```json
{
  "title": "相机新品体验会",
  "size": [1080, 1920],
  "fps": 30,
  "cps": 5.0,
  "voice": null,
  "follow": "assets/关注动效/关注动效-黑底.mp4",
  "talk_still": "outputs/2026-11-相机体验会/封面/上一条出镜.png",
  "grade": "none",
  "notes": "来源：……",
  "segments": [
    {"name": "钩子", "text": "全场只有我一个业余的？",
     "shots": [{"src": "inputs/2026-11-相机体验会/sdr/IMG_0105.mov", "in": 1.6, "note": "翻转屏打开"}]},

    {"name": "地点", "text": "新机开售这天，我去了品牌的线下体验会。",
     "shots": [{"src": "inputs/2026-11-相机体验会/sdr/IMG_0101.mov", "in": 0, "speed": "fit", "note": "展厅入口，摇到体验区"}]},

    {"name": "反差", "text": "来的基本上都是专业摄影师，像我这样的爱好者，好像真的只有我一个。",
     "shots": [{"type": "talk", "note": "出镜"}]},

    {"name": "难点", "text": "它的翻转屏、防抖、对焦追踪，每一项都要单独设置。",
     "shots": [
       {"src": "inputs/2026-11-相机体验会/sdr/IMG_0108.mov", "in": 5.3, "dur": 0.62, "note": "“翻转屏”"},
       {"src": "inputs/2026-11-相机体验会/sdr/IMG_0109.mov", "in": 4.6, "dur": 0.64, "speed": 2, "note": "“防抖”，2 倍速"},
       {"src": "inputs/2026-11-相机体验会/sdr/IMG_0110.mov", "in": 2.0, "blur": [[730, 335, 190, 105]], "note": "背后屏幕露出别人的账号，打码"}
     ]},

    {"name": "现场原声", "live": true, "text": "我们这次最想解决的，是新手不会设置的问题。",
     "shots": [{"src": "inputs/2026-11-相机体验会/IMG_0112.mov", "in": 6.7, "dur": 3.9, "audio": 1.0, "note": "产品经理台上讲解"}]},

    {"name": "速查表", "text": "所以我把这些设置整理成了一张速查表。",
     "shots": [{"type": "placeholder", "title": "速查表页待做", "note": "速查表介绍页，三行随口播出现"}]},

    {"name": "结尾", "text": "关注我，一起把相机玩明白。", "tempo": 1.18, "fixed": 4.0,
     "shots": [{"type": "follow"}]}
  ]
}
```

## 顶层字段

| 字段 | 意思 |
|---|---|
| `title` | 片名，写进分镜脚本标题 |
| `size`、`fps` | 默认 1080×1920、30，按账号配置 |
| `cps` | 估时用的口播语速（每秒字数），按账号配置，真人约 5 |
| `voice` | 实录口播文件。录之前写 `null`；`align_vo.py --write` 会自动填 |
| `follow` | 结尾关注动效的视频 |
| `talk_still` | 可选。还没录出镜时，占位卡用这张图做底（比如上一条出镜的一帧） |
| `grade` | 全片调色：`none`（默认）或 `light`（轻 S 曲线 + 饱和度微提）。素材发灰、多种来源要统一观感时用 `light` |
| `notes` | 写进分镜脚本开头的说明，比如外部事实的来源、剪映里要补什么 |

## 段（segments 里的每一项）

| 字段 | 意思 |
|---|---|
| `name` | 段名，短（钩子、地点、反差……） |
| `text` | 这段的口播，也是字幕。现场原声段写原声说了什么 |
| `vo` | `[入, 出]`：这段话在实录里的起止秒数。`align_vo.py` 填，也可以手改 |
| `tempo` | 这段口播变速（不变调），比如结尾"关注我"说慢了用 1.15–1.2 |
| `fixed` | 固定这段的时长（秒），口播短于它就补静音。结尾动效段一般写 4 |
| `live` | `true` 表示现场原声段：不念口播，声音来自片段本身（片段要写 `audio`）。时长 = 各片段 `dur` 之和 |
| `shots` | 这段的画面，按顺序播 |

段的时长：录之前按 `text` 估（字数 ÷ cps + 标点停顿 + 0.35 秒气口）；录之后 = (出 − 入) ÷ tempo。

## 画面（shots 里的每一项）

`type` 不写时，有 `src` 的按扩展名判断是视频（`clip`）还是图片（`image`）。

| type | 用途 | 字段 |
|---|---|---|
| `clip` | 视频片段 | `src`、`in`（入点秒数）、`dur`、`speed`、`layout`、`blur`、`audio`、`denoise`、`sharpen` |
| `image` | 照片、做好的图文页 PNG | `src`、`dur`、`layout`、`blur` |
| `talk` | 出镜：取实录里同一时间段的画面，口型同步。录之前显示占位卡 | `note` |
| `follow` | 结尾关注动效，播完定格到段尾 | — |
| `placeholder` | 还没有的画面，显示黄色"占位"卡 | `title`、`note` |

画面字段：

| 字段 | 意思 |
|---|---|
| `dur` | 这个画面多长。不写的那一个画面填满这段剩下的时间（只有一个不写最好）；都写了的，最后一个画面自动补齐 |
| `speed` | 倍速：`1.5` 加速；`"fit"` 把从入点到素材结尾刚好塞进这个画面的时长 |
| `layout` | `auto`（默认：接近竖屏就铺满，否则横屏居中）、`fill`（裁切铺满）、`band`（横屏素材放中间，背景用同一画面放大模糊） |
| `cy` | `band` 时素材中心的 y 坐标，默认画面正中 |
| `blur` | 打码框列表 `[[x, y, 宽, 高], ...]`，坐标是成片画面（1080×1920）里的。用样片抽帧量，框要盖住手持晃动的范围（看首、中、尾三帧） |
| `audio` | 片段原声音量，默认 0（静音）。现场原声段写 1；想留一点现场环境声写 0.1–0.2 |
| `denoise` | `auto`（默认：需要放大的素材自动轻降噪）、`none`、`light`、`strong` |
| `sharpen` | `auto`（默认：需要放大的自动 cas 0.5）、`0` 关掉、或 0–1 的数 |
| `note` | 画面说明，写进分镜脚本。写具体："“翻转屏”：屏幕翻到前面"，不写"素材 3" |

## 改时间线的规矩

- 段名、段的顺序定了就别乱改；新增段用新名字，删段直接删。
- 录好口播以后，**口播段的时长由实录决定**，改画面（换入点、加减镜头）不影响口播；不要再改 `text` 的内容（除了按实录修正字幕）。
- 一个画面里要展示"变化"的（翻转屏幕、切换模式）：变化过程可以加速（1.3–2 倍），变化后的结果用原速停留，让人看清。空镜（展厅、走廊）可以加速到 1.5 倍左右。
