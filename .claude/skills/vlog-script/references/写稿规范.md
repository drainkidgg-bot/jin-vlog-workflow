# 写稿规范

这些规则来自 Jin（@卷小jin）做 vlog 时一句句的修改意见，每条都踩过坑。下面的例子统一用一个虚构的场景：一个摄影爱好者去了一场相机新品体验会。账号自己的偏好（身份钩子、系列回调、口号）在账号配置里。

## 钩子和开头

- **开头要短**：一句话就引出钩子，不堆解释。"这台相机，我只上手了十分钟。"比任何三句话的开场都好。改稿时如果为了准确把开头改长了，宁可换一个说法，也不要变长。
- **钩子优先用创作者的身份反差**：创作者在这个场合"不该出现"或"少见"的那个点（比如一个业余爱好者出现在一屋子专业摄影师中间）。这是个人号最有辨识度的东西，具体看账号配置。
- **问句钩子要能在片中兑现**：开头问"全场只有我一个业余的？"，中段就要有出镜亲口确认。
- **工具型钩子要等东西做完**：比如"我做了个一键 xxx 的工具"，要等有完整演示、分发方式也定了再用；没做完时只在片中提一句"做好了单独出一期"。
- **语气词开头可以留**：实录里自然带出的"啊，真的只有我……"比删掉更自然。

## 结构

- 常用的骨架：钩子 → 地点和场合 → 反差兑现（出镜）→ 难点 / 过程 → 回调上一条或个人收获 → 观点（出镜）→ 结尾关注。
- **讲工具、讲方法之前先讲难点**，再引出工具，听起来更顺（比如先说新机设置项多、上手难，再说自己整理了一份速查表）。
- **出镜放在情绪和观点的地方**：反差兑现、最后的观点。其他段用现场画面，出镜太多像念稿。
- **同一次素材可以拆两条**：赶热点的那条先用故事讲；教程、工具等做完能演示了再单独出一条。
- 系列内容可以回调上一条（"上一次我还在台下看，这次轮到我上手了"），用上一条的画面做呼应。

## 措辞

- **不能超出事实**：没核实的去掉或模糊处理（"第一届"不确定就不说）；"国内第一批"多半查不实，改用能查实的（"开售当天"）；不说"一个人做完"这类和团队分工冲突的话，改成只说自己负责的那部分。
- **名人的话**：和原话有出入时写"引用""用了这句话"，不写成原话。人物身份用最新的（对方已经卸任 CEO，就不能再写 CEO）。
- **不写"只说了一句话"这类夸张的概括**：对方实际说了很多，就不能这么写。
- **画面状态要和口播对上**：画面里是暂停键，就不能说"接着播"；口播说"一键"，演示就得真的一条指令跑完。
- **关键信息句用规整的说法**：列举功能写"翻转屏、防抖、对焦追踪"，不用"转过来、不抖了、跟着走"这种拟声式口语。录的时候创作者自己说得口语一点没关系。
- **避开平台极限词**：最、第一、唯一、首批；"第一台"改"首款"。不写暗示背书的（官方认证、某某邀请、官方规范 → 公布的规范）。
- 印象类的说法留余地："好像只有我一个业余的"，不写"唯一的业余玩家"。

## 事实

- 外部事实查到来源再写，来源记进时间线的 `notes` 或分镜脚本末尾，最后进长期记录。
- 新品类、新设备的说法先查现状：说"XX 还做不到"之前，先确认是不是已经有人、有工具做到了。
- 创作者的个人经历由创作者提供；有证据的（截图、邀请函）注明，只是印象的写得留余地。
- 素材里没拍到的事，只能口播转述，不能剪一段别的画面当"证据"。

## 口播节奏

- 估时按真人口播约每秒 5 字（账号配置里的 `cps`），不按机器配音。
- 一段一个意思，长句在逗号处断开；提词版按逗号、句号切小段高亮。
- 结尾口号每条固定（账号配置），接结尾关注动效。
