# 角度、口播和分镜

要读的参考：

- `references/写稿规范.md`：钩子、结构、措辞和事实的规则。写稿、改稿前必读。
- `references/时间线格式.md`：`时间线.json` 每个字段的意思和例子。排时间线前必读。
- 账号配置里的定位、身份钩子、口播语速、结尾口号、时长。

脚本在 vlog-pipeline 的 `scripts/` 里（`.claude/skills/vlog-pipeline/scripts/`）。

## 流程

1. **先给角度，不急着写稿**：读素材盘点、创作者给的背景、以前做过的几条。给 2–3 个角度，每个写清：钩子（第一句话原文）、核心观点、结构（5–8 段，每段一句话 + 用哪段素材）、和以前内容比新在哪、还缺什么素材。说出你推荐哪个、为什么。等创作者选。
2. **写口播，排时间线**：选定后写 `outputs/<条>/时间线.json`。一段 = 一句或一个意思，写清这段说什么（`text`）和配什么画面（`shots`，入点照素材盘点里的时间点）。出镜的段用 `talk`；没拍、没做的画面用 `placeholder`；现场原声段用 `live`。
3. **检查时长**：`python3 scripts/timeline.py outputs/<条>/时间线.json`。它按账号配置的口播语速估时（真人约每秒 5 字），列出每段起止和警告（素材不够长、素材找不到）。总长超出账号配置的时长就删，删的是信息，不是把话说快。
4. **核查**：派子代理 `vlog-fact-checker`，给它时间线和素材盘点的路径。按它的报告改，改不了的（需要创作者确认的事实）列出来问。
5. **出给创作者审的三样**：
   ```
   python3 scripts/timeline.py <时间线.json> --docs outputs/<条> --tag vN
   python3 scripts/render.py <时间线.json> outputs/<条>/样片-vN-占位版.mp4 --draft --label "样片 vN · 占位版 · 字幕仅供参考"
   ```
   分镜脚本（表格：时间 / 段 / 画面 / 声音 / 字幕）、纯文本口播、样片。样片里没录的出镜会显示占位卡；时间线写了 `talk_still`（以前出镜的一帧）的，占位卡用这一帧做底，更像成片。发给创作者时附上这版改了什么、哪几句最想听意见。
6. **改稿**：创作者的意见改进时间线，重新生成 vN+1。只改了某几句也重出口播全文，方便对照。通用的意见回写到 `references/写稿规范.md`（写日期和原因）或账号配置。
7. **提词版**：口播定稿后出提词版，同时给纯文本口播：
   ```
   python3 scripts/prompter.py <时间线.json> outputs/<条>/提词版-vN.mp4
   ```
   整段一起显示、正在念的小段高亮、底部预告下一句；出镜的段标「出镜 · 看镜头」，现场原声段标「不用念」；前 3 秒倒计时。告诉创作者：对着它**一条连录**，全片口播都用这一条（出镜段的画面也从这一条里取，口型才对得上）；说错了停一下、从那句开头重说就行，剪的时候取最后一遍；录的时候顺口改词没关系，精剪会按实录来。
8. **录完交给 vlog-cut**。

## 口播稿和提词版、字幕三者一致

口播稿是唯一准绳：提词版、纯文本口播、样片字幕都从时间线的 `text` 生成，所以只要改时间线就不会对不上。创作者录完以后，以实录为准回改 `text`（vlog-cut 做），因为字幕要和实际说的一字不差。
