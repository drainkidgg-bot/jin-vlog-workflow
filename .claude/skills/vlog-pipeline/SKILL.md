# Vlog 剪辑总流程

这是 **Jin's Vlog Workflow**：Jin（小红书、抖音 @卷小jin）做 vlog 的方法，从他自己的视频里一条条验证出来，整理成通用的流程、规范和脚本。

这套流程做的是一类很常见的短视频：创作者去了一个现场（活动、展会、发布会、探店、旅行），手机拍了一堆素材，回来想剪成一条 1 分钟左右的竖屏视频，自己出镜口播讲清楚一件事。小红书、抖音为主。

分工：Claude 负责看素材、想角度、写稿、排时间线、出提词版和样片、按实录口播精剪、准备封面和发布文案；创作者负责提供背景、拍板、对着提词版录口播、在剪映里加字幕和 BGM、自己点发布。

开工前先读 `docs/账号配置.md`：账号定位、口播语速、结尾口号和动效、交付规格、封面版式、红线、长期记录放哪，都在那里。各 skill 里写"按账号配置"的地方，值都从那份文件来。**没有这份文件**，说明是第一次用，先按下面「第一次用」一节把它建出来。

## 阶段和分工

| 阶段 | 用哪个 skill / 子代理 | 交付（在 `outputs/<YYYY-MM-主题>/`） | 停下来等创作者 |
|---|---|---|---|
| 1 素材盘点 | `vlog-footage` | 素材副本进 `inputs/`；`素材盘点.md`（每段拍到了什么、说了什么、能怎么用） | 补背景、补素材 |
| 2 角度和结构 | `vlog-script` | 2–3 个角度和钩子，各自的结构和缺的素材 | 选角度 |
| 3 口播和分镜 | `vlog-script`；交稿前跑子代理 `vlog-fact-checker` | `时间线.json`、`分镜脚本-vN.md`、`口播-vN.txt`、`样片-vN-占位版.mp4` | 审稿、看样片节奏 |
| 4 录口播 | `vlog-script` 的提词版 | `提词版-vN.mp4` + 纯文本口播 | 创作者对着提词版一条连录 |
| 5 精剪 | `vlog-cut`；交付前跑子代理 `vlog-video-qa` | `精剪-vN-含口播无字幕.mp4`，时间线按实录更新 | 看精剪 |
| 6 剪映收尾 | 创作者自己 | 字幕、标签、BGM | — |
| 7 封面和发布 | `vlog-publish` | 封面底图和抠图、`发布文案.md` | 挑封面、创作者自己点发布 |
| 8 归档和复盘 | `vlog-publish` 的归档、复盘两节 | 只留终版；长期记录；经验回写 skill | 确认清理过程文件 |

还没拍完的也能往下走：缺的出镜用旧出镜的静帧占位、缺的演示用占位卡，时间线照常排，先出样片对节奏（已验证）。

## 每条视频的文件

```
inputs/<YYYY-MM-主题>/            素材副本。收到就复制进来，聊天软件的缓存会被清
outputs/<YYYY-MM-主题>/
  状态.md                         这一条做到哪了（模板见 assets/状态模板.md）
  素材盘点.md                     素材表、每段的画面和原声、可用片段
  素材盘点/                       联系表、转写结果（过程文件）
  时间线.json                     唯一的时间线：口播、分段、每段的画面
  分镜脚本-vN.md、口播-vN.txt      从时间线生成，给创作者审
  样片-vN-占位版.mp4               对节奏用，烧了参考字幕和版本标签
  提词版-vN.mp4                   录口播用
  精剪-vN-含口播无字幕.mp4          交给创作者进剪映
  封面/                           封面候选帧、抠图
  发布文案.md
```

- **时间线是唯一准绳**：口播、分镜脚本、提词版、样片、精剪都从 `时间线.json` 生成。改稿就改时间线，再重新生成，不要手改分镜脚本。格式见 vlog-script 的 `references/时间线格式.md`。
- **版本号只增不改**：每次给创作者看的东西编号（v1、v2……），旧版不覆盖，到归档时一起清理。新版开头说清相比上一版改了什么。
- **每条一个 `状态.md`**：每完成一步更新一行，新会话先读它。

## 工具箱

整套流程的脚本都在本 skill 的 `scripts/` 里（下面写的 `scripts/xxx` 都指这里，在项目里是 `.claude/skills/vlog-pipeline/scripts/`）。需要 ffmpeg（带 libx264）、Python 3 + Pillow；转写另建 venv 装 mlx-whisper（Apple 芯片）或 faster-whisper。

| 脚本 | 做什么 | 谁用 |
|---|---|---|
| `probe.py` | 素材体检：时长、尺寸、帧率、HDR、音量，标出要先处理的 | vlog-footage |
| `to_sdr.py` | iPhone HDR 转 SDR（macOS 用 avconvert） | vlog-footage |
| `contact_sheet.py` | 抽帧拼联系表；也能按时间点取原尺寸帧 | 各阶段 |
| `transcribe.py` | whisper 转写，可带逐字时间 | vlog-footage、vlog-cut |
| `timeline.py` | 读时间线，算时长，生成分镜脚本和口播稿 | vlog-script、vlog-cut |
| `prompter.py` | 提词版视频 | vlog-script |
| `render.py` | 样片（`--draft`，占位 + 参考字幕）和精剪 | vlog-script、vlog-cut |
| `align_vo.py` | 实录口播逐段对齐，写回时间线 | vlog-cut |
| `qa.py` | 成片体检：规格、响度、黑帧、定格、剪接点跳帧 | vlog-cut、vlog-video-qa |
| `follow_card.py` | 生成结尾关注动效（每个账号做一次） | 第一次用 |
| `lift_subject.swift` | macOS 抠图，封面上叠产品或手持设备 | vlog-publish |

脚本有问题就直接修，修完在本文件末尾的修改记录里记一笔。

## 第一次用

`docs/账号配置.md` 不存在时，先把账号设置好再开工：

1. 复制 `assets/账号配置模板.md` 到 `docs/账号配置.md`，一项项问创作者填上。最要紧的是：账号定位（一句话）、创作者的身份和最有辨识度的点（钩子从这里来）、结尾口号、平台。拿不准的项先写"待定"，做第一条时再定。
2. 要一张账号头像（和平台上同一张方图），用 `scripts/follow_card.py` 生成结尾关注动效，放进 `assets/关注动效/`，路径写进账号配置。先出黑底版给创作者看，要叠在画面上的再出 `--bg alpha` 或 `--bg green`。
3. 项目根目录没有 `CLAUDE.md` 的，用 `assets/CLAUDE模板.md` 建一个。
4. 建 `inputs/`、`outputs/`、`assets/` 三个目录。

## 新会话开工时

- **接着做某一条**：先读那一条的 `状态.md`，再读它提到的最新文件。
- **新开一条**：读账号配置；看 `outputs/` 里以前做过的几条（和长期记录里的视频页），这样才能说清这条的新增价值、能不能回调上一条。然后进 vlog-footage。
- 确认子代理 `vlog-fact-checker`、`vlog-video-qa` 能派出去（在 `.claude/agents/`；会话开着时才新建的，要新开会话才认得）。派不出去就按它们文件里写的要求自己做一遍，在状态里记一笔。

## 请创作者判断时

- 给要看的东西本身：样片、精剪的文件链接，改动表，候选图，不要让人去翻目录。
- 说清这次要判断什么、有哪几个选项、你的建议。
- 能一起问的一次问完，创作者的时间最稀缺。

## 越做越好

创作者的意见如果是通用的（不只针对这一条），除了改这一条，还要回写：

- 账号层面的偏好（钩子路数、封面版式、口号）→ `docs/账号配置.md`，写日期和原因。
- 做法层面的（剪辑、写稿、发布的规则）→ 对应 skill 的规范，并在那个 skill 末尾的「修改记录」加一行（日期、改了什么、为什么）。

现在的大部分规则，都是前几条视频里创作者一句句意见攒下来的。

## 必须守住的

1. **事实不夸大**：没核实的说法去掉或模糊处理；名人原话不确定时写"引用""用了这句话"，不写成原话；外部事实给出来源。素材里没拍到的，只能口播转述，不能剪成画面"证据"。
2. **不合成真人**：不用 AI 合成真人的脸或声音，不用 AI 超分处理人脸。
3. **引用要规矩**：别人的片段用官方来源，保留署名水印，只截几秒；下载网络视频前先向创作者确认来源、文件和大小。
4. **隐私**：画面里露出的账号、ID、工牌、他人信息要打码。
5. **开头要短**：一句话引出钩子。
