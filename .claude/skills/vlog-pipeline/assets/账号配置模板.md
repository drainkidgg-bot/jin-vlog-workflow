# 账号配置：<账号名>

vlog-* skill 写的是通用做法，凡是写"按账号配置"的地方都读这份。换一个账号，只要换掉这份文件和 `assets/` 里的头像、关注动效。

改这份文件要写日期和原因。拿不准的项先写"待定"，做第一条时再和创作者定。

## 账号

| 项 | 值 |
|---|---|
| 名字 | 例：@xxx（小红书、抖音同名） |
| 平台 | 例：小红书、抖音同步发同一条 |
| 定位（一句话） | 例：用普通人的视角，把新出的数码产品玩明白 |
| 创作者是谁 | 例：摄影爱好者，本职是老师。最有辨识度的点：业余玩家出现在专业的场合 |
| 为什么做这个号 | 例：个人影响力 / 涨粉变现。影响选题和复盘看什么 |
| 频率、时长 | 例：1–2 周一条，60–80 秒 |
| 结尾口号 | 例：关注我，一起把相机玩明白。（每条固定） |

## 钩子和标题的路数

- 例：钩子优先用身份反差（业余爱好者 vs 专业场合）。
- 例：小红书标题用"身份 + 大名字 + 问号"；系列内容可以回调上一条。
- （做了几条以后，把创作者认可的、否掉的都记在这里，写日期）

## 口播和录制

| 项 | 值 |
|---|---|
| 语速 | 每秒约 5 字（真人口播），写进时间线的 `cps` |
| 怎么录 | 例：对着提词版一条连录出镜，全片口播和出镜画面都用这一条 |
| 用什么录 | 例：手机前置，竖屏，上半身 |
| AI 配音 | 例：不用。用了的话发布时要勾 AI 声明 |

## 交付

| 项 | 值 |
|---|---|
| 规格 | 1080×1920，30fps |
| Claude 交什么 | 例：精剪，无字幕、无标签、含口播和现场原声 |
| 创作者自己加什么 | 例：在剪映里加字幕、标签、BGM |
| 字幕区 | 例：竖屏约 70%–78% 高度，图文页内容避开 |
| 结尾关注动效 | `assets/关注动效/关注动效-黑底.mp4`（用 `follow_card.py` 生成，4 秒） |
| 图文页、卡片风格 | 例：浅灰底、白色圆角卡、黑色胶囊按钮，参考 <网站或文件> |
| 调色 | 例：默认不调（`grade: none`） |

## 封面

| 项 | 值 |
|---|---|
| 版式 | 例：底图是创作者出镜正脸 + 抠出的产品元素；色块两行大字 + 英文小字 |
| 颜色 | 例：每条换一个色块颜色，保持同样的明度和鲜艳程度 |
| 封面字 | 约 10 字，两行 |
| 尺寸 | 小红书 3:4（1080×1440）；抖音 9:16，主体放中间 3:4 |

## 红线和授权

- 平台红线：极限词、背书暗示、导流（见 vlog-publish 的发布前检查）。
- 引用别人的片段：官方来源、保留署名、只截几秒；下载前先问创作者。
- 不用 AI 合成真人的脸和声音。
- 花钱的事（投流、买素材、付费工具）先问创作者。
- 例：不能露的东西（公司内部画面、同事的脸）：

## 长期记录

- 例：每条定稿后在 `outputs/<条>/归档.md` 写视频页（目标受众、核心观点、事实核验、素材清单、终版口播、封面标题、发布链接和数据）。
- 例：或者写进自己的笔记软件（比如 Notion、飞书文档），写明位置和模板。
