# 封面、发布和归档

发布由创作者自己点。你准备好东西、做完检查，交给创作者。账号配置里有封面版式、标题路数、平台和红线。

脚本在 vlog-pipeline 的 `scripts/` 里（`.claude/skills/vlog-pipeline/scripts/`）。

## 封面

1. **挑脸**：从出镜实录里抽候选帧。先 `contact_sheet.py <实录> <表.jpg> --at <一串时间> --crop <人脸区域>` 看表情（每 0.2 秒一格扫一遍出镜段，挑睁眼、表情自然、嘴型好看的），再挑 4–6 张用 `--full outputs/<条>/封面` 存原尺寸 PNG，标上特点（微笑开口、挑眉、闭嘴浅笑……）给创作者选。
2. **产品元素**（可选）：从现场素材里挑一帧（比如手拿着半折的设备），`swift scripts/lift_subject.swift <帧.png> <输出.png>` 抠成透明 PNG。它会打印实例序号并存每个实例的遮罩，先看遮罩，只要其中几个就在命令末尾写序号（`0,2`）。只能在 macOS 14+ 上用。
3. **封面字**：约 10 字、分两行，抓眼球。版式、配色按账号配置（系列内保持一致；换颜色时保持原色的明度和鲜艳程度，白字要清楚）。给色值就给 2–3 个具体的 HEX 让创作者选。
4. **尺寸**：小红书竖版 3:4（1080×1440）；抖音 9:16（1080×1920），个人页格子会裁成 3:4，主体和标题放中间 3:4 范围里。发布前再核对平台当前要求。

封面的最终排版一般由创作者在设计工具或剪映里做，你给底图、抠图、字和色值。

## 发布文案：`outputs/<条>/发布文案.md`

```
# 发布文案 · <片名>

封面字：<第一行> ／ <第二行>（／ 英文小字，按账号配置）

## 小红书
**标题**（≤20 字）：
**正文**：两三段口语，把视频里最意外的一点往前推一步；有引用的在末尾注明出处
**话题**：#… #…

## 抖音
**标题**（可以长一些，带搜索词）：
**描述**：
**话题**：

## 发布前检查
- [ ] 极限词：没有最、第一、唯一、首批；序数用"首款"这类能查实的
- [ ] 背书暗示：没有"官方认证""某某推荐""某某邀请"
- [ ] 导流：没有外链、"评论区领取"、"私信"、其他平台名
- [ ] 引用：别人的片段、App 画面都注明出处，署名水印保留
- [ ] AI 声明：用了 AI 配音、克隆音色、AI 画面就勾选；全是真人口播就不用
- [ ] 隐私：画面里的账号、ID 已打码
```

写法：

- **封面字和标题不一样**：封面抓眼球；标题换一种说法，把信息往前推一步，带上搜索关键词。
- **标题要有钩子**，不能只陈述事实。"XX 相机上手体验"没有钩子；"只玩了十分钟，我就想买这台相机？"有。Jin 常用的路数是"身份 + 有分量的人或事 + 问号"，系列内容回调上一条爆款；每个账号的路数写在账号配置里。
- 小红书标题优先抓人，搜索词放进正文和话题；抖音标题可以长一些，直接带搜索词。
- 还没做完的东西只预告（"做好了单独出一期"），不放链接。
- 发之前查一遍平台当前的审核规则，有新的红线写回账号配置。

## 发布后

1. 创作者发完，问要两个平台的链接。"已发布"必须有链接或创作者确认，不能自己推断。
2. **归档**（创作者说可以清理时再做）：每条只留终版——精剪终版视频、口播终版、分镜脚本终版、发布文案、封面底图和抠图。时间线也留着（以后要重剪、引用画面时有用）。其余过程文件（旧版本、样片、提词版、联系表、转写、SDR 副本、`inputs/` 里的素材副本）**移到废纸篓，不直接永久删除**；先列清单给创作者看。素材原件在哪（手机、下载目录、微信）写进长期记录，方便以后找。
3. **长期记录**：按账号配置的「长期记录」一节，定稿时建视频页，写全：目标受众、核心观点、相比以前的新增价值、事实核验（外部事实带来源，个人经历注明由创作者提供）、措辞取舍、素材清单、终版口播、结构、封面和标题、终版文件位置。发布后回填平台、链接、日期。
4. **回写经验**：这条里创作者的通用意见，确认都已经回写到对应 skill 或账号配置（见 vlog-pipeline「越做越好」）。

## 复盘和投流

- 发布后 3 天、7 天看一次数据，回填长期记录：播放、完播、点赞、收藏、评论、涨粉。
- 读评论：观众纠错要核实，确实错了的在评论区回应，并回写到写稿规范。
- **投流（小红书薯条）**：在自然流量还在涨的时候尽快投；目标选「粉丝关注量」；晚高峰前开始；小额分批投，按单个粉丝的成本决定要不要追投。名人肖像、引用片段可能让审核更严。花钱的事由创作者决定。
