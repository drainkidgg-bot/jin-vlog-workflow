# 素材盘点

先弄清楚素材里**实际**有什么，再决定讲什么。创作者记得的和真正拍到的经常对不上：素材里没有的画面，只能由创作者口播转述，不能剪成画面"证据"（已验证）。

脚本在 vlog-pipeline 的 `scripts/` 里（`.claude/skills/vlog-pipeline/scripts/`）。

## 流程

1. **先复制**：收到素材就复制进 `inputs/<YYYY-MM-主题>/`，用 `cp -p` 保留拍摄时间。微信缓存（`~/Library/Containers/com.tencent.xinWeChat/...`）会被自动清理，下载目录也可能被创作者清掉。文件名保持原样（`IMG_0101.MOV`），方便和手机相册对上；聊天软件里那种哈希文件名，复制时改成 `微信-<内容>.mp4`。
2. **体检**：`python3 scripts/probe.py inputs/<目录> --loudness`，表格贴进素材盘点。要处理的问题它会标出来：
   - **低于 1080p**：多半是微信转发压过（会压到 720p，画质差很多）。主力镜头请创作者让对方用"原文件"或 AirDrop 重发。拿不到就在精剪里做降噪 + 放大 + 锐化，但提升有上限，要提前说清。
   - **HDR**：iPhone 默认拍 HDR（HLG），直接剪会发灰发白。`python3 scripts/to_sdr.py <文件>... --out <临时目录>/sdr`，后面所有剪辑都用 SDR 版本。转出来的文件放临时目录或 `inputs/<目录>/sdr/`，不要覆盖原件。
   - **没有声音 / 几乎没声音**：只能当空镜。
3. **看画面**：每段素材出一张联系表 `python3 scripts/contact_sheet.py <视频> <输出.jpg>`（默认约 40 格，每格标时间），用 Read 看图。找关键瞬间时缩短间隔（`--every 0.25`）或只看局部（`--crop 宽:高:x:y`，比如屏幕上的字、人脸）。联系表放 `outputs/<条>/素材盘点/`。
4. **听原声**：转写每段有声音的素材。第一次先建 venv（放临时目录，不进项目）：
   ```
   python3 -m venv <临时目录>/whisper-venv
   <临时目录>/whisper-venv/bin/pip install mlx-whisper      # Apple 芯片；其他电脑装 faster-whisper
   <临时目录>/whisper-venv/bin/python scripts/transcribe.py inputs/<目录>/*.MOV --prompt "人名，产品名，英文词" --out outputs/<条>/素材盘点/转写
   ```
   `--prompt` 写上素材里会出现的专有名词，能少听错很多。模型用 large-v3-turbo，不要换 large-v3：嘈杂现场它会幻听出没说过的话。静音段落末尾冒出的"谢谢大家""请订阅"之类，是 whisper 的幻听，忽略。
5. **写素材盘点**：`outputs/<条>/素材盘点.md`，格式见下。
6. **问创作者**：把盘点发给创作者，同时问清背景（见下面「要问的」）。

## 素材盘点的格式

```
# <主题> · 素材盘点

## 素材表
| 文件 | 时长 | 拍到了什么 | 原声 | 能怎么用 |
|---|---|---|---|---|
| IMG_0105 | 0:08 | 1.6s 翻转屏打开；5.0s 对着展台试拍 | 无人声，现场环境声 | 钩子画面；"翻转屏"那个词 |

## 关键瞬间
- IMG_0109 2.4s：手持走动，画面很稳（适合"防抖"那个词）
- ……

## 现场原声里能用的句子
- IMG_0112 6.7–10.6s：产品经理台上讲解 "…"（可以做原声段）

## 要处理的
- 720p 的主力镜头、HDR、要打码的地方（画面里露出的账号、ID、工牌）

## 还缺什么
- 讲 X 需要的画面没拍到 → 补拍 / 用口播转述 / 占位
```

"拍到了什么"写具体的时间点和动作，后面排时间线时直接用这些入点。

## 要问的

- 这是什么场合、哪天、谁邀请的、创作者在里面是什么角色（钩子多半从身份反差里来）。
- 想表达的核心是什么，和之前哪条内容有关系。
- 现场能不能拍、有没有不能露的东西。
- 创作者说的事实里，哪些有证据（活动页截图、邀请函），哪些是印象（"好像只有我一个业余的"）。印象类的话术后面要写得留余地。
- 还能不能补拍、补录（比如回家补一段出镜）。

## 几条容易踩的坑

- **引用别人的成片**（包括自己上一条视频）做素材时，联系表要看到剪接点：入点落在剪接点之后，否则会带进上一个镜头的几帧，看起来像跳帧（已验证）。
- **avconvert 失败不一定报错**：`to_sdr.py` 以输出文件为准，转完检查它打印的尺寸和 HDR=False。
- **手机竖拍的视频带旋转标记**：`probe.py` 显示的是换算后的显示尺寸；直接用 ffmpeg 处理时它会自动按旋转来，不用手动转。
- 素材里背景屏幕、电脑上露出的账号信息、团队 ID，盘点时就记下位置，精剪时打码。
